# Compact quality gates

- Evidence/rights: source, actor reference, brand, external upload, commercial use.
- Product truth: core verb, visible change, reward/claim, CTA destination, first landing action.
- Drama continuity: endpoint, emotion, relationship, OOC risk, identity, costume, props, topology, axis/eyeline, light/color, sound field.
- Shot causality: new information/change, motivated movement/edit, world result before UI.
- Visual assets: stable version, complete image, readable hands/faces/objects, no accidental text.
- Text/localization: exact English, spelling, safe area, mobile readability, timing.
- Video: corresponding storyboard and selected character references bound per shot; playable output/audio; approved final-card append.
- Delivery: approved state, no open critical issue, stable URL/file, provider provenance.

Hard-block unmotivated axis/movement/edit/focus errors; transitions used to hide continuity; OOC or feature-recitation dialogue; unsupported mechanics; unauthorized identity/voice/upload; UI sound before action; unreadable text; or a text-only visual card presented as generated media.

Ordinary project runs may generate/revise up to three shots independently. Do not block this as multiple submissions unless strict `single_final_video_pass` was explicitly selected.
