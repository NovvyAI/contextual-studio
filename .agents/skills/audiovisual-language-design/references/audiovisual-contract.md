# Audiovisual execution contract

Use this reference for production-level specificity.

## Composition and continuity

State shot size and its narrative reason; subject position, headroom, lead room, negative space, depth layers, and 9:16 safe areas; camera height, pitch, viewing side, focal-length class, perspective, depth impression, and focus target. Preserve axis, eyeline, spatial anchors, topology, prop count, light direction, and screen direction unless an approved beat changes them.

## Movement

Every movement includes `trigger`, `path`, `direction`, `speed`, `easing`, `duration`, `stabilization`, and `end_frame`. Reject ornamental movement, focus drift, unmotivated whip pans, or movement used to conceal an error.

## Timing terminology

- Undercrank: capture below playback frame rate for accelerated/stepped motion.
- Overcrank: capture above playback frame rate and play normally for slow motion.
- Frame interpolation creates intermediate frames in post; it is not overcranking.
- Video degradation changes resolution, grain, scan lines, or signal quality; it is not traditional undercranking.
- Flashback/flashforward needs a trigger, temporal distinction, purpose, duration, and return point.
- Montage needs one theme and information gain per shot. Jump cuts need an explicit narrative purpose.

## Light, edit, sound, causality

Describe light source/direction/quality/temperature/ratio, exposure, black/highlight behavior, skin tone, palette, grain, and cross-shot matching. Define edit entry/exit, action or eyeline match, J/L cut, rhythm, transition, and sound bridge. Preserve: `intent → physical/world action → visible result → UI/VFX feedback → character reaction → unresolved hook`.
